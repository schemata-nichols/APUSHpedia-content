## Description

0. Greetings.

1. [APUSHpedia](<index.md>) is a project under [Schemata](https://schemata-nichols.github.io/), a student-led association under [Nichols School](https://www.nicholsschool.org/).

2. APUSHpedia aims to organize [(AP) United States History](https://apstudents.collegeboard.org/courses/ap-united-states-history)  in a [Wikipedia](https://www.wikipedia.org/)-like form for students and educators.

3. APUSHpedia is formatted as a [Quartz](https://quartz.jzhao.xyz/) site with an [Obsidian](https://obsidian.md) vault. Content in APUSHpedia generally consists of Obsidian-flavored [Markdown](https://en.wikipedia.org/wiki/Markdown) files. 

4. **APUSHpedia is currently in development**. Changes (to *any* content/regulation) may be made for development purposes.

5. P.S. Link to Github Repo: [schemata-nichols/APUSHpedia](https://github.com/schemata-nichols/APUSHpedia)
