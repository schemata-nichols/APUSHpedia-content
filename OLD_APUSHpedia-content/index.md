## Description

0. Greetings.

1. [APUSHpedia](<index.md>) is a project aiming to organize the contents/concepts in **AP United States History** in a structured manner, in order to improve the learning/teaching experience of students/teachers as well as to provide a knowledge base for future projects.

2. APUSHpedia, *currently*, is formatted as an [Obsidian](https://obsidian.md) vault and displayed as a static site generated by [Quartz](https://quartz.jzhao.xyz/). Thus, most contents in APUSHpedia are in Obsidian-flavored [Markdown](https://en.wikipedia.org/wiki/Markdown) files. 

3. Contents in APUSHpedia are drafted with LLMs *and checked/maintained by students and educators*. We're trying our best to make the site reliable. However, if you find any error, please contact us.

4. APUSHpedia is completely **free**. *The main repository is under MIT license. The content repository is yet private.*

5. **APUSHpedia is currently in development**. Changes (to *any* content/regulation) may be made for development purposes.
